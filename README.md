## 📌 Sobre o projeto
Sistema de gestão para bibliotecas escolares desenvolvido para simplificar o controle de acervo, o cadastro de alunos e o fluxo de empréstimo de livros, substituindo processos manuais por uma solução moderna, ágil e intuitiva.

## 🚀 Funcionalidades

- [ ] Login de dos bibliotecários usando 2FA
- [ ] Gerenciamento de acervos
- [ ] Gerenciamento de alunos
- [ ] Gerenciamento e rastreamento de empréstimos

## 🛠️ Tecnologias
- **Linguagem:** C#
- **Framework web:** Asp.NET Razor Pages
- **Testes:** xUnit
- **Banco de dados:** PostgreSQL
- **Containers:** Docker & Docker Compose

## 🏃‍➡️ Como executar

Clone o projeto
```bash
git clone https://github.com/AnndreJunior/Archivum.git
cd Archivum
```

Execute via docker compose
```bash
docker compose up -d
```

Acesse a aplicação em http://localhost:8080. Para acessar os logs entre em http://localhost:5341.
